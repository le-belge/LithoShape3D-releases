# LithoShape3D — Releases

Ce depot ne contient aucun code source : il sert uniquement a heberger les
binaires de distribution (installeurs Windows/macOS) pour les beta-testeurs
de [LithoShape3D](https://github.com/le-belge/LithoShape3D), dont le code
source reste prive.

Les liens de telechargement sont dans l'onglet [Releases](../../releases).

**Premiere installation ?** Lisez le [guide d'installation en 1 minute](INSTALLATION.md)
(le logiciel n'est pas encore signe : un avertissement s'affiche au premier lancement, c'est normal).

Un probleme ou une idee ? Ouvrez une [Issue](../../issues).
