BETA PROGRAM — VERSION 1.0 RC3

Become a beta tester

LithoShape3D is getting close to version 1.0. I'm looking for a few motivated users to seriously test this Release Candidate before the public release.

LithoShape3D turns your photos into light objects ready for 3D printing: flat or arched lithophanes, LithoSphere, LithoClock, LithoBox, LithoLetters and custom shapes, on Windows and Mac.

A Release Candidate is an almost-final version: RC3 may still contain bugs. The goal is to really test the software (printing if possible), report problems and retest the fixes.

Places are limited. Applying does not automatically guarantee access.
